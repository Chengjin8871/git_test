# git_test

Git 操作练习仓库。

## 说明

- 本仓库用于测试 `git init` / 提交 / 推送到 GitHub 的基本流程。
- 分支：`master`（非 `main`）。
- 推送方式：SSH（`git@github.com:Chengjin8871/git_test.git`）。

## 安全注意

`API Key/` 目录（含各类密钥、token 等敏感文件）**已在 `.gitignore` 中被整体排除**，不会被提交或推送到远程。请勿手动 `git add -f` 该目录下的文件。

## 常用命令

```bash
git add -A
git commit -m "你的说明"
git push
```
